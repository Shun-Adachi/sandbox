# ワークフロー構築プラン(設計メモ)

Dify 1.16.1(セルフホスト)上で構築するワークフローの計画。
それぞれ完成後に DSL エクスポート(YAML)とスクリーンショットをこの docs/ に置く。

## 1. rag-qa — ナレッジベース Q&A(RAG)

- ナレッジ(ドキュメントアップロード → チャンク分割 → weaviate へベクトル化)を作成し、
  「知識取得 → LLM 回答生成」のチャットフローを組む。
- 見どころ: 検索スコア閾値・Top-K の調整、引用元表示、該当なし時のフォールバック分岐。

## 2. doc-extract — 非構造化テキストの構造化抽出(ワークフロー)

- 入力テキストから項目を JSON で抽出するバッチ向けワークフロー。
  LLM ノードの構造化出力 + コードノードでの検証を組み合わせる。
- 見どころ: IF/ELSE 分岐によるバリデーション失敗時の再試行・エラーハンドリング。
- llm-api / llm-batch-pipeline テーマと対になる位置付け(同じ処理をコードで再現する)。

## 3. agent-tools — エージェント(ツール利用)

- エージェントノード + ツール(Web 検索等)で多段推論するフロー。
- 見どころ: ツール選択の様子、イテレーション上限などの制御。

## 環境メモ

- モデルプロバイダー: OpenAI プラグイン(langgenius/openai 1.0.3)インストール済み。
  API キーは UI の「設定 → モデルプロバイダー」または console API で登録する。
- ポート: HTTP 80 / SSL 8443(ホスト側 443 が使用中のため変更)。
